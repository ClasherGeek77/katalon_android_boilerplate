# Mobile-Katalon-Example-Project 📱

[![Katalon Studio](https://img.shields.io/badge/Katalon%20Studio-Mobile%20Automation-success?logo=katalon)](https://katalon.com/)
[![Appium](https://img.shields.io/badge/Appium-Integration-blue?logo=appium)](https://appium.io/)

A complete demonstration of Mobile Test Automation (Android) using **Katalon Studio** and **Appium**. This repository acts as a blueprint for implementing scalable mobile testing architectures.

## 🎯 Objective
To establish a robust framework for testing native, hybrid, and mobile web applications, showcasing the initialization of Appium servers, handling device capabilities (DesiredCapabilities), and managing mobile element locators reliably.

## 🏗 Architecture & Technologies
- **Test Engine**: Katalon Studio (Appium wrapper)
- **Target OS**: Android (APK) & iOS (IPA)
- **Design Pattern**: Page Object Model (POM)

## ⚙️ Key Concepts Demonstrated
1. **Desired Capabilities**: Configuring device name, platform version, and app paths dynamically.
2. **Mobile Record & Spy**: Using Katalon's built-in tools to capture robust XPaths for tricky mobile elements.
3. **App State Management**: Starting an application, handling permissions, running tests, and closing cleanly.

## 🚀 Getting Started
1. Ensure Appium and Node.js are installed on your machine.
2. Connect a real device via ADB or launch an Android Emulator / iOS Simulator.
3. Open the project in Katalon.
4. Execute via the "Android" run option.
